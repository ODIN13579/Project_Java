# DSN-10 UI handoff

**Tích hợp backend BUILD1-04:** dùng [contract MVP](../api/build104-mvp.md) cho login AccessTokenResponse, Device/Telemetry REST, cookie/origin và plain WebSocket. Các màn hình bên dưới giữ thiết kế toàn hệ thống; House/Zone selector cần ID đã biết, chưa có API House/Zone, GET CountLog, alert/control/report. REST catch-up hiện có cho Telemetry, chưa có cho CountLog. Chưa có kết quả kiểm thử UI React thực để kết luận đạt NFR thời gian hiển thị.
